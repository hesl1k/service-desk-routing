# API-контракт

Сервис работает на порту `8002`.

- `GET /health` — проверка готовности.
- `POST /route` — расчёт распределения.
- `/docs` — Swagger UI.

`POST /route` принимает два формата.

## Внутренний формат

Используется аналитическим пакетом и LP-ядром. Верхний уровень содержит `operators`, `tickets` и `config`.

## Внешний формат

Используется для интеграции с системой Service Desk. Верхний уровень содержит `agents`, `tickets`, `handle_time_minutes`, `planning_horizon_minutes` и `config`. Перед вызовом LP-ядра данные приводятся к внутреннему формату.

Ответ всегда содержит стоимость обработки, штрафы, назначения, неназначенные тикеты, время расчёта и детализацию по каждому назначенному тикету.
