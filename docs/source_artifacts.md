# Использованные материалы групп

## Группа 1

Из исходного LP-ядра сохранены структура входа `operators/tickets/config`, ограничения по уровню, навыкам, каналам, capacity и чат-слотам, а также состав результата: стоимость, штрафы, назначения и время решения.

## Группа 2

Из REST-сервиса сохранены `GET /health`, `POST /route`, единый ответ для успешного и ошибочного запроса, Swagger/OpenAPI и проверка входных данных.

## Группа 3

Из контейнерного проекта сохранены отдельный API-сервис на порту 8002, healthcheck, Docker Compose и запуск без прав администратора внутри контейнера.

## Группа 4

Нагрузочный сценарий переведён с заглушки на реальный `POST /route`. В отчёте используются технические показатели API: RPS, среднее время ответа, медиана, p95, p99 и доля ошибок.

## Группа 5

Сохранены пять сценариев, baseline-эвристика, расчёт стоимости и экономии, CSV/JSON-выгрузки и Streamlit-дашборд. Итоговый показатель экономии рассчитывается по суммарной стоимости всех сценариев.
