# Проверка проекта

Выполнены следующие проверки:

- компиляция всех Python-файлов;
- 9 автоматических тестов `pytest`;
- прямой расчёт пяти сценариев;
- расчёт тех же сценариев через запущенный REST API;
- сравнение прямого и API-результата;
- контроль целостности CSV и JSON;
- нагрузочный прогон 100 RPS в течение 5 секунд;
- проверка OpenAPI-схемы;
- статическая проверка Docker Compose.

Результаты прямого и API-расчёта совпали. Нагрузочный прогон завершился без ошибок.
