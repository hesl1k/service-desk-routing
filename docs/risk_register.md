# Реестр рисков

| Риск | Признак | Действие |
|---|---|---|
| API не запускается | `/health` недоступен | Проверить зависимости, порт 8002 и журнал uvicorn |
| Формат запроса не совпадает | HTTP 422 | Сверить запрос с `docs/openapi.json` и примерами в `docs/` |
| LP не находит решение | `status=infeasible` | Разрешить очередь либо проверить навыки, каналы, capacity и уровни |
| Расчёт слишком долгий | Растёт `solver_time_ms` | Уменьшить размер пакета, разделить горизонт или ограничить набор кандидатов |
| Экономия ниже 7% | `target_reached=false` | Проверить стоимость ресурсов, штрафы и наличие конфликтных сценариев; результат не подгонять |
| Дашборд пустой | Нет CSV в `data/output` | Запустить `python -m analytics.pipeline --lp-source direct` или API-режим |
| Нагрузочный тест даёт ошибки | `error_rate_percent>0` | Снизить интенсивность, проверить таймауты и логи API |
| Docker не собирается | Ошибка `docker compose build` | Проверить доступ в интернет для pip, версию Compose и свободное место |
| AFRT/ART нельзя подтвердить | Нет временных отметок | Использовать пометку «моделируемые» или добавить реальные timestamps |
